# RWA Tokenization Agent & Launchpad

## Overview
Command-line interface (CLI) engineered for the automated tokenization of Real World Assets (RWA) and liquidity pool initialization on the Solana blockchain.

## Technical Stack
* **Network:** Solana (Devnet)
* **Core SDK:** `@solana/web3.js`
* **Metadata Standard:** Metaplex Foundation
* **Liquidity Protocol:** Meteora Dynamic Bonding Curve SDK

## Prerequisites
* Node.js (v18.0.0 or higher recommended)
* npm or yarn
